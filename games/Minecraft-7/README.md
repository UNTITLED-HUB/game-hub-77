# Minecraft Mini — 생존과 크리에이티브

청크 기반으로 생성되는 넓은 블록 세계를 탐험하는 독립 미니 샌드박스입니다. 지형·바이옴·동굴·광석·낮과 밤, 동물과 몬스터, 제작·화로·상자·물·TNT를 지원합니다. 원작 리소스를 사용하지 않고 이 프로젝트에서 구현한 게임입니다.

## 기본 조작

- **W / A / S / D** 또는 방향키: 이동
- **마우스**: 시점 이동. 게임 화면 클릭 후 마우스 잠금, `Esc`로 잠금 해제
- **Space**: 점프. 크리에이티브에서는 빠르게 두 번 눌러 비행 전환
- **Shift**: 웅크리기 · 비행 중 하강
- **Ctrl** 또는 `W` 두 번: 달리기
- **좌클릭 누르기**: 블록 캐기 또는 공격
- **우클릭**: 블록 설치, 아이템 사용, 음식 먹기
- **휠 / 1–9**: 핫바 선택
- **E**: 인벤토리·제작대 열기
- **Q**: 아이템 버리기 (`Ctrl+Q`는 전체 스택)
- **T**: 채팅 및 명령 입력 · **/**: 명령어 입력 · **F1**: HUD 숨기기 · **F3**: 디버그 정보 · **Esc**: 메뉴
- 키는 설정 → 키 설정에서 바꿀 수 있습니다.
- **가운데 클릭**: 바라보는 블록 선택

## 모바일

왼쪽 조이스틱(또는 방향 패드)으로 이동하고 화면을 드래그해 시점을 움직입니다. 짧게 탭하면 설치·사용, 꾹 누르면 캐기·공격입니다. 점프·캐기·놓기·웅크리기·달리기·비행·내려가기·버리기·채팅·일시정지 버튼이 있고, 핫바 오른쪽 ⋯ 버튼으로 인벤토리를 엽니다.

**버튼 배치 편집**(설정 → 터치 컨트롤, 게임 메뉴, 타이틀 화면의 격자 아이콘): 버튼을 끌어 옮기고, 버튼마다 크기(50–200%)와 표시 여부를 정할 수 있습니다. 격자 맞춤, 개별/전체 초기화, 취소를 지원하며 위치는 화면 비율로 저장돼 가로·세로 전환에도 유지됩니다.

## 설정

- **비디오**: GUI 크기(자동/1–4), 밝기, 시야 거리(2–10), 렌더 해상도, 최대 프레임, 파티클, 구름, 걷기 흔들림, 달리기 시야 효과, 피격·폭발 흔들림
- **음악 및 소리**: 주 음량, 음악, 블록, 생물, 플레이어, 버튼 클릭음
- **조작**: 마우스 감도·반전, 자동 점프, 웅크리기/달리기 누르기·전환, **키 설정**(키 재지정, 충돌 표시, 초기화)
- **터치 컨트롤**: 표시(자동/항상/숨김), 조이스틱/방향 패드, 고정/터치한 곳 조이스틱, 터치 감도, 버튼 크기·불투명도, 탭해서 설치, 꾹 눌러 캐기 시간, 진동, 좌우 반전 배치
- **인터페이스**: HUD 크기, 채팅 표시·불투명도, 조준점, 아이템 이름, 좌표·FPS 표시, 메뉴 배경 흐림, 타이틀 배경 속도
- **난이도**: 평화로움·쉬움·보통·어려움 (게임 중 설정 첫 화면)

## 모드와 진행

- **생존**: 체력·허기·도구 내구도와 아이템 수집·제작을 관리합니다.
- **크리에이티브**: 자유 비행과 아이템 팔레트를 사용합니다.
- 월드는 브라우저 저장소에 자동 저장됩니다. 사용 중인 브라우저에서만 이어할 수 있습니다.

## 생성 텍스처

`textures/`에 생성한 블록, 자연물, 아이템, 모바일 조작 시트를 넣었습니다. 3D 월드의 주요 블록과 돼지·소·양·좀비·거미에 사용합니다. 몬스터는 머리·몸통·팔·다리의 앞뒤·좌우·상하 면을 분리해 표시합니다. 일부 블록과 HUD 표시는 기존 내장 텍스처를 사용합니다.

게임은 샌드박스 iframe에서 실행됩니다. 별도 호스팅에서 텍스처가 적용되려면 이미지 응답에서 CORS를 허용해야 합니다. 파일을 불러오지 못하면 내장 텍스처로 대체됩니다. 모바일 화면에서는 왼쪽 조이스틱으로 이동하고 오른쪽 이미지 버튼으로 동작합니다.

## UI 디자인

메뉴·버튼·인벤토리·제작 화면은 돌 질감 버튼, 회색 컨테이너 패널, 슬롯, 레시피 책(빨간 칸 = 재료 부족, 누르면 필요한 재료가 제작 칸에 미리 표시), 크리에이티브 탭으로 구성했습니다. UI 텍스처는 실행 중에 코드로 생성하므로 별도 이미지가 필요 없습니다. 픽셀 글꼴은 `fonts/Galmuri11.woff2`(SIL OFL, `fonts/Galmuri-LICENSE.txt`)를 쓰며, 불러오지 못하면 CDN → 시스템 글꼴 순으로 대체됩니다.
