# Minecraft Mini — 생존과 크리에이티브

청크 기반으로 생성되는 넓은 블록 세계를 탐험하는 독립 미니 샌드박스입니다. 지형·바이옴·동굴·광석·낮과 밤, 동물과 몬스터, 제작·화로·상자·물·TNT를 지원합니다. 원작 리소스를 사용하지 않고 이 프로젝트에서 구현한 게임입니다.

## 기본 조작

- **W / A / S / D** 또는 방향키: 이동
- **마우스**: 시점 이동. 게임 화면 클릭 후 마우스 잠금, `Esc`로 잠금 해제
- **Space**: 점프. 겉날개를 입고 공중에서 한 번 더 누르면 활공. 크리에이티브에서는 빠르게 두 번 눌러 비행 전환
- **Shift**: 웅크리기 · 비행 중 하강
- **Ctrl** 또는 `W` 두 번: 달리기
- **좌클릭 누르기**: 블록 캐기 또는 공격
- **우클릭**: 블록 설치, 아이템 사용, 음식 먹기
- **휠 / 1–9**: 핫바 선택
- **E**: 인벤토리·제작대 열기
- **Q**: 아이템 버리기 (`Ctrl+Q`는 전체 스택)
- **F**: 양손 바꾸기(왼손) · **F5**: 시점 전환(1인칭 → 3인칭 뒤 → 3인칭 앞) · **G**: 비행 전환(크리에이티브)
- **T**: 채팅 및 명령 입력 · **/**: 명령어 입력(입력하는 동안 추천어가 떠요. **Tab** 또는 탭으로 선택, **↑/↓**로 이동. 추천이 없을 때 ↑/↓는 이전에 보낸 내용) · **F1**: HUD 숨기기 · **F3**: 디버그 정보 · **Esc**: 메뉴
- 키는 설정 → 키 설정에서 바꿀 수 있습니다.
- **가운데 클릭**: 바라보는 블록 선택

## 모바일

왼쪽 조이스틱(또는 방향 패드)으로 이동하고 화면을 드래그해 시점을 움직입니다. 짧게 탭하면 설치·사용, 꾹 누르면 캐기·공격입니다. 음식·활·망원경·방패처럼 누르고 있어야 하는 아이템을 들고 꾹 누르면 캐기 대신 먹기·활 당기기(떼면 발사)·확대·막기를 해요. 기본 화면에는 점프·웅크리기·채팅·일시정지·시점 버튼만 보이고, 핫바 오른쪽 ⋯ 버튼으로 인벤토리를 엽니다. 설정 → 터치 컨트롤에서 '간단한 터치 버튼'을 끄면 캐기·사용·달리기·버리기·양손 바꾸기 버튼이 다시 나타나요. 인벤토리의 '빠른 이동/1개씩' 버튼은 '인벤토리 보조 버튼'으로 켤 수 있어요.

**크리에이티브 비행**: 점프 버튼을 빠르게 두 번 탭하거나 비행 버튼을 누르면 날아요. 날 때는 점프 = 위로, 내려가기·웅크리기 = 아래로(누르고 있는 동안만) 움직여요.

**인벤토리 터치 조작**: 아이템을 끌어서 다른 칸에 놓으면 옮겨지고(다른 아이템이 있으면 맞바꿈), 아이템을 든 채로 여러 칸을 문지르면 고르게 나눠 놓아요(제작 칸에도 가능). 길게 누르면 절반 집기, 두 번 탭하면 빠른 이동, 제작 결과 칸을 길게 누르면 가능한 만큼 한꺼번에 제작해요. 레시피 책에서 같은 레시피를 다시 누르면 재료가 한 세트씩 더 들어가요.

**버튼 배치 편집**(설정 → 터치 컨트롤, 게임 메뉴, 타이틀 화면의 격자 아이콘): 버튼을 끌어 옮기고, 버튼마다 크기(50–200%)와 표시 여부를 정할 수 있습니다. 격자 맞춤, 개별/전체 초기화, 취소를 지원하며 위치는 화면 비율로 저장돼 가로·세로 전환에도 유지됩니다.

## 화로

원작과 같은 규칙으로 구워요.

- 하나 굽는 데 10초 걸리고, 석탄·숯 하나로 8개를 구워요. 원목·판자는 1.5개, 막대기·묘목·그릇·양털은 0.5개, 나무 도구는 1개, 블레이즈 막대는 12개, 석탄 블록은 80개, 용암 양동이는 100개예요. 용암 양동이는 다 타면 빈 양동이가 남아요.
- 연료는 구울 수 있는 재료가 있고 결과 칸에 자리가 있을 때만 불이 붙어요. 한 번 붙은 불은 재료를 빼도 끝까지 타요.
- 재료를 다른 것으로 바꾸거나, 불이 붙은 채 구울 수 없게 되면 진행도가 처음부터 시작돼요. 불이 꺼지면 진행도가 천천히 줄어요.
- 훈연기는 음식만, 용광로는 광석·원석만 구워요. 둘 다 두 배 빠르지만 연료도 두 배 빨리 타서 석탄 하나로 굽는 개수는 같아요.
- 연료 칸에는 연료와 빈 양동이만 넣을 수 있어요.

## 캐릭터 · 왼손 · 시점

- **캐릭터**(설정 → 캐릭터): 클래식 체형(넓은 팔, 4픽셀)과 슬림 체형(얇은 팔, 3픽셀)을 고르고 피부·머리·옷 색과 머리 모양을 바꿀 수 있어요. 기본 캐릭터 4종(바위·노을·숲지기·새벽)은 이 프로젝트에서 직접 디자인했어요. 1인칭 팔, 3인칭 모델, 인벤토리 미리보기에 함께 적용되고 입은 갑옷도 보여요.
- **왼손**: 인벤토리의 방패 모양 칸, 핫바 왼쪽에 표시. `F`/터치 '양손 바꾸기' 버튼으로 손 아이템과 바꿔요. 오른손으로 쓸 게 없으면 왼손 아이템(블록·횃불·음식·양동이 등)을 사용하고, 활을 쏠 때는 왼손 화살부터 써요.
- **시점**: `F5` 또는 터치 오른쪽 위 눈 버튼. 3인칭에서는 카메라가 벽을 뚫지 않게 당겨져요.

## 전투

원작(1.9 이후) 규칙을 따라요. 무기마다 공격력·공격 속도가 있고(예: 다이아몬드 검 7 / 초당 1.6, 다이아몬드 도끼 9 / 1.0, 맨손 1 / 4.0), 조준점 아래 게이지가 다 차야 최대 피해가 나요(피해 = 공격력 × (0.2 + 0.8 × 게이지²)).

- **치명타**: 게이지가 찬 상태로 떨어지면서 때리면 ×1.5 + 노란 별 파티클 (달리기·비행·물속 제외)
- **달리며 때리기**: 강한 밀치기, 달리기가 끊겨요
- **휩쓸기**: 땅에서 검으로 게이지 가득 → 바로 옆 몹에게 1 피해
- 누르고 있으면 게이지가 찰 때마다 자동으로 다시 때려요. 터치는 몹을 짧게 탭하면 공격해요.
- 설정 → 전투: 전투 방식(공격 쿨다운 / 연타 구버전), 공격 게이지 표시, 데미지 숫자 표시

## 갑옷과 도구

- **갑옷**: 가죽·금·철·다이아몬드 투구/흉갑/레깅스/부츠. 방어력·내구도는 원작 수치를 따르고, 낙하·익사·굶주림 피해는 막지 못해요. 인벤토리 왼쪽 갑옷 칸에 넣거나 손에 들고 사용해서 입어요. 체력 위에 방어력 막대가 표시돼요. 가죽은 소에게서 얻어요.
- **가위**: 잎(×15)·양털(×5)을 빨리 캐고, 잎·풀을 블록 그대로 얻어요. 양에게 사용하면 양털을 깎아요(시간이 지나면 다시 자라요).
- **활과 화살**: 사용 버튼을 누르고 있다가 떼면 발사해요. 끝까지 당기면 치명타가 나고, 박힌 화살은 다시 주울 수 있어요. 화살 재료는 깃털 대신 실을 써요(부싯돌 + 막대기 + 실).
- **침대**: 양털 3 + 판자 3. 밤에 사용하면 아침까지 자고, 리스폰 지점이 돼요.
- **나침반 / 시계**: 들고 있으면 리스폰 지점 방향·거리, 시간을 화면에 보여줘요. 레드스톤 대신 석탄으로 만들어요.

## 고친 문제

- 동물을 때리는 중 잔디·풀이 같이 부서지던 문제: 몹을 한 번 때린 누름 동안에는 블록을 캐지 않고, 풀·꽃·횃불은 실제 모양으로 판정해서 그 뒤의 몹을 조준할 수 있어요.
- 한 프레임보다 짧은 클릭이 무시되던 문제, 활을 당기다 인벤토리를 열면 화살이 발사되던 문제, 시야 거리 2에서 로딩이 끝나지 않던 문제, 시야 가장자리 청크 일부가 안 그려지던 문제.

## 캐기 연출

블록 금은 원작처럼 10단계로 가운데에서 바깥으로 갈라지며 쌓이고, 캐는 동안 팔·도구가 원작과 같은 궤적으로 계속 휘두르며 맞은 면에서 조각이 튀어요. 손에 든 아이템과 땅에 떨어진 아이템은 1픽셀 두께의 입체 스프라이트로 보여요.

## 겉날개

흉갑 칸에 겉날개를 입고, 점프한 뒤 **공중에서 점프를 한 번 더** 누르면 펼쳐져 활공해요(누르고 있을 필요 없음). 원작과 같은 활공 물리를 써서 아래를 보면 속도가 붙고, 위를 보면 속도를 높이로 바꿔 올라가요. 벽에 빠르게 부딪히면 피해를 입어요. 활공 중 **폭죽 로켓**을 사용하면 바라보는 방향으로 가속하고, 겉날개 + 팬텀 막을 조합하면 수리돼요. 착지하거나 물에 들어가면 자동으로 접혀요.

## 지형 생성 (새 월드)

이 업데이트 이후 만든 월드는 새 지형 생성기를 써요. 이전에 만든 월드는 저장된 집과 건축물이 어긋나지 않도록 기존 지형을 그대로 유지해요.

- **대륙과 바다**: 큰 대륙, 깊은 바다, 완만한 해안이 이어져요. 땅이 낮게 꺼진 곳에는 호수가 생겨요.
- **강**: 골짜기를 따라 굽이치는 강이 바다까지 이어지고, 높은 산을 만나면 끊겨요. 추운 곳의 강은 얼어요.
- **마을 부지**: 마을이 생기는 곳은 반경 약 60블록이 평평하게 다져지고, 바깥쪽으로 자연 지형과 완만하게 이어져요. 마을 안에는 동굴이나 협곡 구멍이 생기지 않아요.
- **산맥**: 능선이 날카로운 산이 높이 250 가까이 솟아요. 높은 곳은 바위가 드러나고 눈이 덮이며, 가파른 비탈은 돌·자갈로 바뀌어요. 산자락에는 꽃이 많은 초원이 있어요.
- **바이옴 17종**: 바다·얼어붙은 바다(빙산)·해변·강·평원·숲·자작나무 숲·어두운 숲·벚나무 숲·타이가·설원(얼음 가시)·늪·사막·악지(색색의 테라코타 층과 계단식 고원)·산·눈 덮인 봉우리·초원. F3 화면에 현재 바이옴이 표시돼요.
- **나무**: 큰 참나무, 굵은 줄기의 짙은 참나무, 분홍 벚나무, 키 큰 가문비나무와 자작나무, 잎이 늘어진 늪 나무가 추가됐어요. 청크 경계에서도 나무 모양이 끊기지 않아요.
- **식물**: 바이옴마다 꽃과 풀이 달라요(초원·벚나무 숲의 꽃밭, 타이가의 고사리, 어두운 숲의 버섯). 물가에는 사탕수수가 자라요.
- **지하**: 구불구불한 동굴, 깊은 곳의 큰 동굴, 지표까지 열린 협곡이 생겨요. 높이 -45 아래 동굴은 용암 호수예요. 점적석 동굴과 이끼 동굴, 드물게 자수정 정동(방해석 껍질)이 있어요. 화강암·섬록암·안산암 덩어리와 심층암 지대의 응회암, 0~8 높이에서 서서히 바뀌는 심층암 경계도 생겨요.
- **광석**: 석탄·철·구리·금·청금석·다이아몬드가 높이별로 분포하고, 산에는 철과 에메랄드가 더 있어요.

## 구조물

생성 방식은 새로 생성되는 지형에 적용되고, 새 월드의 '월드' 탭에서 '구조물 생성'을 끌 수 있어요.

- **마을**: 원작 최신 버전처럼 종이 있는 우물(회의 장소)에서 길이 뻗어 나가고, 길은 지형을 따라 깔려요. 집은 각자 기초를 다져 길을 향해 지어지고, 작은 집·큰 집·농장(물길과 작물)·대장간·도서관·가축 우리·가로등이 있어요. 평원(참나무)·숲(가문비나무)·설원(눈 덮인 지붕)·사막(사암) 양식이 다르고, 주민과 철 골렘이 살아요. 집에는 침대와 직업 블록(훈연기·용광로·대장장이 작업대·화살 작업대·베틀·퇴비통·지도 제작대·책장)이 있어요.
- **무너진 차원문**: 일부가 부서진 흑요석 틀, 우는 흑요석, 네더랙·마그마 바닥, 보물 상자.
- **사막 피라미드**: 탑 두 개와 주황/파랑 테라코타 무늬, 아래 숨겨진 방의 상자 4개와 TNT 바닥.
- **이글루**: 설원의 눈 돔, 침대·화로·작업대.
- **던전**: 지하의 이끼 낀 조약돌 방, 몬스터 생성기(가까이 가면 좀비·스켈레톤·거미가 나와요)와 상자.
- **요새**: 용암 위 엔드 차원문 방, 네 방향 복도, 도서관과 보물 방.
- **엔드 시티와 엔드 함선**: 엔드 바깥 섬의 퍼퍼 탑(나선 계단으로 올라감)과 옆에 떠 있는 함선. 함선 상자에 겉날개가 있어요.

## 생성 텍스처

`textures/`에 생성한 블록, 자연물, 아이템, 모바일 조작 시트를 넣었습니다. 3D 월드의 주요 블록과 돼지·소·양·좀비·거미에 사용합니다. 몬스터는 머리·몸통·팔·다리의 앞뒤·좌우·상하 면을 분리해 표시합니다. 일부 블록과 HUD 표시는 기존 내장 텍스처를 사용합니다.

게임은 샌드박스 iframe에서 실행됩니다. 별도 호스팅에서 텍스처가 적용되려면 이미지 응답에서 CORS를 허용해야 합니다. 파일을 불러오지 못하면 내장 텍스처로 대체됩니다. 모바일 화면에서는 왼쪽 조이스틱으로 이동하고 오른쪽 이미지 버튼으로 동작합니다.

## UI 디자인

메뉴·버튼·인벤토리·제작 화면은 돌 질감 버튼, 회색 컨테이너 패널, 슬롯, 레시피 책(빨간 칸 = 재료 부족, 누르면 필요한 재료가 제작 칸에 미리 표시), 크리에이티브 탭으로 구성했습니다. UI 텍스처는 실행 중에 코드로 생성하므로 별도 이미지가 필요 없습니다. 픽셀 글꼴은 `fonts/Galmuri11.woff2`(SIL OFL, `fonts/Galmuri-LICENSE.txt`)를 쓰며, 불러오지 못하면 CDN → 시스템 글꼴 순으로 대체됩니다.
