# Minecraft Mini — 생존과 크리에이티브

청크 기반으로 생성되는 넓은 블록 세계를 탐험하는 독립 미니 샌드박스입니다. 지형·바이옴·동굴·광석·낮과 밤, 동물과 몬스터, 제작·화로·상자·물·TNT를 지원합니다. 원작 리소스를 사용하지 않고 이 프로젝트에서 구현한 게임입니다.

## 기본 조작

- **W / A / S / D** 또는 방향키: 이동
- **마우스**: 시점 이동. 게임 화면 클릭 후 마우스 잠금, `Esc`로 잠금 해제
- **Space**: 점프. 크리에이티브에서는 빠르게 두 번 눌러 비행 전환
- **Shift**: 웅크리기 · 비행 중 하강
- **Ctrl** 또는 `W` 두 번: 달리기
- **좌클릭 누르기**: 블록 캐기 또는 공격
- **우클릭**: 블록 설치, 아이템 사용, 음식 먹기
- **휠 / 1–9**: 핫바 선택
- **E**: 인벤토리·제작대 열기
- **Q**: 아이템 버리기 (`Ctrl+Q`는 전체 스택)
- **T**: 채팅 및 명령 입력 · **/**: 명령어 입력 · **F3**: 디버그 정보 · **Esc**: 메뉴
- **가운데 클릭**: 바라보는 블록 선택

## 모바일

화면 방향 패드로 이동하고 화면을 드래그해 시점을 움직입니다. 공격·설치·점프·웅크리기/비행 버튼을 사용하세요. 블록을 길게 누르면 채굴합니다.

## 모드와 진행

- **생존**: 체력·허기·도구 내구도와 아이템 수집·제작을 관리합니다.
- **크리에이티브**: 자유 비행과 아이템 팔레트를 사용합니다.
- 월드는 브라우저 저장소에 자동 저장됩니다. 사용 중인 브라우저에서만 이어할 수 있습니다.

## 생성 텍스처

`textures/blocks.png`에는 게임에 등록된 60개 블록 아이콘(광석, 나무·장식·기능 블록, 물, 8색 양털 포함)을 8×8 스프라이트 시트로 담았습니다. `textures/items.png`에는 막대기·광물·음식·양동이·5단계 도구 20종 등 40개 아이템 아이콘을 담았습니다. 인벤토리, 핫바, 제작 목록에서 전부 사용합니다. 3D 월드의 세부 표면은 게임 내부 타일 텍스처로 따로 렌더링됩니다.
