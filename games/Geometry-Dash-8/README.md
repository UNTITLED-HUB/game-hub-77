# Geometry Dash Mini

자동으로 달리는 큐브를 점프시켜 장애물을 넘는 리듬 액션 미니게임입니다. 세 개의 자체 제작 코스, 진행률, 연습 모드, 재도전을 지원합니다. 원작 레벨과 음악은 포함하지 않습니다.

## 조작

- **Space / ↑ / W**, 마우스 클릭 또는 터치: 점프
- 누르고 있기: 착지 후 연속 점프
- **P** 또는 허브의 일시정지 버튼: 일시정지/재개
- 충돌 후 클릭 또는 Space: 다시 도전

연습 모드는 안전한 구간에서 체크포인트를 기록합니다. 코스와 리듬은 이 프로젝트에서 만든 자체 콘텐츠입니다.
